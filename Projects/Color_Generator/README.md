# 🌍 Random Color Generator App

A modern, responsive React UI utility for generating and displaying random color codes. Built with React, Vite, and designed with real-time UI background switching supporting both HEX and RGB string formats.

> **Master state controls, dynamic inline styles, and conditional rendering**

---

## 🛠️ Tech Stack
* **Framework:** React.js (Vite Template)
* **Styling:** Custom Inline CSS
* **Language:** JavaScript (ES6+), HTML, CSS

---

## ✨ Features

- 🔄 **Format Switching** – Toggle dynamically between HEX and RGB text formats seamlessly
- 🎨 **Dynamic Styling** – Live screen background updates driven by reactive state parameters
- 📱 **Fully Responsive** – Centralized layout optimized for mobile viewports using clamping rules
- ⚡ **Lightning Fast** – Vite-powered development with Hot Module Replacement (HMR)
- 🎯 **Modern Styling** – Glassmorphic backdrop blur button layouts with interactive hover logic
- 🚀 **Production Ready** – Clean, maintainable, scalable single-file codebase

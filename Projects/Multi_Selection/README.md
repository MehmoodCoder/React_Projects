# 🌍 Accordion App

A modern, responsive React UI component for showcasing FAQ items. Built with React, Vite, and designed with toggle mechanics supporting both single-expansion and multi-expansion behaviors.

> **Master state toggles, conditional rendering, and active array filtering**

---

## 🛠️ Tech Stack
* **Framework:** React.js (Vite Template)
* **Styling:** Custom CSS
* **Language:** JavaScript (ES6+), HTML, CSS

---

## ✨ Features

- 🔄 **Hybrid State Management** – Toggle dynamically between single-select and multi-select modes
- 🎨 **Modular Component** – Clean, self-contained UI logic separation
- 📱 **Fully Responsive** – Centralized layout handling viewports effortlessly
- ⚡ **Lightning Fast** – Vite-powered development with Hot Module Replacement (HMR)
- 🎯 **Modern Styling** – Flexbox-driven layouts alongside smooth hover animations
- 🚀 **Production Ready** – Clean, maintainable, scalable codebase
